# Retained XO output comparison

This temporary draft diagnoses the three same-store-path NAR hash differences between successful qualifications 41145005348 (8273ea5b) and 41158639922 (e8d8bfbf). It does not certify a release or change the cache. The concrete cause remains unknown until the hosted comparison succeeds.

A read-only PR job runs only for this repository's `diagnostic/retained-nar-comparison` branch. It downloads the two fixed retained artifacts, checks exact run/attempt/source/artifact identity and archive digest, and verifies product/scan GitHub attestations against the qualification workflow and immutable source. It verifies each retained transport part/archive and compressed/decompressed NAR hash. The earlier product hashes must also match the public cache's signed narinfo, verified against the existing Ed25519 cache key. Missing artifacts, unavailable attestations, changed identities or malformed data stop the diagnostic; there is no fallback to rebuilding or a different artifact.

The GitHub token has only contents/actions/attestations read access and is removed before NAR parsing. Trusted host `zstd` and Nix `nar ls` read the fetched output as data. No package program, build script or fetched executable runs; no Nix import, realization, cache push, package publication or signing occurs. Source recipe blobs are hashed with `git show`; they are not evaluated. The archive reader's actual Nix version is recorded, rather than claimed to be the historical producer's exact toolchain.

The job is limited to 60 minutes; the comparison has a 45-minute timeout plus 15-second kill grace. Two CPUs are allowed, with 3 GiB address-space and 1800 CPU-second limits per inherited process, not an aggregate memory quota. Each of the two fixed downloads is capped at its authenticated size (~2.65 GB). ZIP/TAR inventory, member types, sizes and safe paths are checked. A selected NAR is at most 3 GiB, and decompression cannot write past its expected NAR size. Listing output is at most 256 MiB, the final summary 5 MiB, with 2000 differing entries sampled per profile. At least 12 GiB free runner space is required. No resource escalation or automatic retry is included.

Only the bounded JSON summary is uploaded for seven days: relative package paths, types, lengths, executable bits, SHA256 hashes, structured Python bytecode headers, derivation identities and source recipe hashes. File contents, raw NARs, scan reports, tool stderr and symlink targets are not uploaded. All retained data is deleted from the runner in cleanup. Summary paths and identities describe public distributed packages; the report carries no release authority.

Synthetic fixtures run before any artifact download. Full ordinary PR validation and the hosted comparison remain pending at initial publication. Do not merge this temporary diagnostic without separate review; remove it after diagnosis. A failure is a blocked diagnostic, not proof that either retained package is corrupt or that the cache can be overwritten.
